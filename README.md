# Import Data using Transform Maps – ServiceNow

## Project Title

Import Data using Transform Maps (Spreadsheet)

## Project Description

This project demonstrates how spreadsheet data can be imported into ServiceNow using Import Sets and Transform Maps.

The spreadsheet data is uploaded into a ServiceNow Import Set Table, where it is validated and transformed before being inserted or updated in the target banking table.

## Objective

To import banking customer data from a spreadsheet into ServiceNow using an Import Set and Transform Map.

## Technologies Used

- ServiceNow
- Import Sets
- Transform Maps
- Google Sheets
- CSV
- GitHub

## Data Used

The project uses sample banking customer data containing:

- Customer ID
- Customer Name
- Account Type
- Account Number
- Branch
- City
- Phone
- Email
- Balance
- Account Status

## Project Workflow

Google Spreadsheet
        ↓
CSV File
        ↓
ServiceNow Import Set
        ↓
Import Set Table
        ↓
Transform Map
        ↓
Target Banking Table
        ↓
Imported Customer Records
